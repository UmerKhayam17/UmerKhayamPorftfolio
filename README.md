# Umer Khayam — Portfolio

Personal portfolio of Umer Khayam, Full Stack & AI Developer.

## Tech stack

Vite, React, TypeScript, Tailwind CSS, shadcn/ui, Framer Motion, GSAP.

## Getting started

```sh
npm install
npm run dev
```

The dev server runs at http://localhost:8080.

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — production build
- `npm run preview` — preview the production build
